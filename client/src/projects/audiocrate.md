# AudioCrate, Pro Tools Plug-ins and Control Surface

## Description

A Pro Tools plug-in company I co-founded with an audio engineer. As the only software developer on the team, I architected the codebase as a set of focused repos (C++ plug-ins, a Swift control surface, a SvelteKit storefront) and owned every quality gate: PR review, CI/CD, and the production services behind them. I also onboarded my co-founder onto GitHub and an AI-assisted workflow, so he now ships plug-in C++ himself.

## Features

- Architected a multi-repo system: plug-in monorepo, macOS and iPad control surface, storefront, docs hub, and shared agent skills, with one shared SwiftUI UI across plug-in, desktop and iPad
- Reviewed every PR from the co-founder's AI-assisted plug-in work, and taught him collaborative GitHub workflow
- Built all CI/CD in GitHub Actions, including change-aware builds that run only what a PR touched
- Set up and run Supabase, Stripe, Google Cloud, Apple developer accounts, and the audiocrate.io storefront
- Coached the team on agentic development: a shared skills repo, MCP servers, CLI tooling and subagent orchestration
